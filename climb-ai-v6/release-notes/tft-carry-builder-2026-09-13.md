# TFT Carry Builder — 2026-09-13

Production release for the TFT Carry Builder.

- Carry-centric meta starting points with dated performance evidence.
- Item packages separated into Meta Best, Strong Alternative, and Fun / High-Roll.
- Triple Guinsoo's Rageblade Jax remains available as a labelled high-roll line rather than being misrepresented as best-in-slot.
- Team shells are generated from current Riot Data Dragon champion traits and static stats.
- Generated carry builds can be loaded directly into Board Lab for structural scoring and Board Compare testing.
- No Riot match API key or database migration is required.
